# § 20 Vergütung für Verbesserungsvorschläge
1 Einzelne oder mehrere Angestellte gemeinsam können Vorschläge zur Verbesserung der Organisation oder von Arbeitsabläufen an die zuständige Behörde einreichen.
2 Die zuständige Behörde kann einzelnen oder einer Gruppe von Angestellten eine Vergütung von maximal 1000 Franken zusprechen. Auf Antrag der zuständigen Behörde kann das zuständige Departement, die Staatskanzlei oder das zuständige oberste Gericht den Angestellten eine Vergütung von maximal 2000 Franken zusprechen.
