# § 16 Schlussverhandlung
1 Das Schiedsgericht ordnet auf Antrag einer Partei oder von Amtes wegen eine Schlussverhandlung an, wenn eine solche zweckmässig erscheint.
2 An der Schlussverhandlung hat jede Partei Anrecht auf einen Vortrag; das Schiedsgericht kann den Parteien einen zweiten gestatten.
