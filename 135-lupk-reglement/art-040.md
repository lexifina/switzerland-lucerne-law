# Art. 40 Invaliden-Kinderrente
1 Versicherte, die eine ganze Invalidenrente beziehen, haben für jedes Kind, das im Fall ihres Todes eine Waisenrente beanspruchen könnte, Anspruch auf eine Invaliden-Kinderrente in der Höhe der Waisenrente.
2 Versicherte, die eine Teilinvalidenrente beziehen, haben unter den gleichen Voraussetzungen für jedes Kind Anspruch auf eine dreiviertel, auf eine halbe oder auf eine viertel Invaliden-Kinderrente.
